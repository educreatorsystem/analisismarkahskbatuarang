# Sistem Analisis Peperiksaan – SEKOLAH KEBANGSAAN BATU ARANG

Versi sistem untuk SEKOLAH KEBANGSAAN BATU ARANG. Perubahan hanyalah identiti sekolah, lencana dan pautan konfigurasi sumber data.

## GitHub Pages
1. Muat naik `index.html` ke bahagian root repository.
2. Buka **Settings > Pages** di GitHub.
3. Pilih **Deploy from a branch**, branch `main`, folder `/(root)`.
4. Simpan dan akses URL GitHub Pages selepas penerbitan.

## Google Sites
Kaedah dicadangkan: `Insert > Embed > By URL` dan masukkan pautan GitHub Pages anda setelah diterbitkan.
Jika hendak menampal kod terus, guna fail `.txt` yang dibekalkan berasingan dan `Embed > Embed code` di Google Sites. Fungsi browser/API mungkin terhad oleh polisi Google Sites.

## Nota
Pastikan Google Apps Script mempunyai kebenaran Web App yang sesuai dan URL CSV ditetapkan sebagai published-to-web. Sila uji fungsi penyimpanan selepas penerbitan.
